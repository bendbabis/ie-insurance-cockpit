# Logo

Aucun logo propriétaire n'est embarqué dans le projet.

Pour afficher le logo officiel :

- **Sans toucher au dépôt** : Configuration → Identité visuelle → charger le fichier (PNG ou SVG, fond transparent, version blanche pour la barre latérale noire). Il est conservé dans le navigateur et utilisé sur les exports PowerPoint.
- **Pour toute l'équipe** : déposer ici `logo.svg` (barre latérale) et `logo.png` (exports PowerPoint, ≈ 900 px de large), récupérés depuis le portail de marque. Ne pas publier ces fichiers dans un dépôt public si leur licence ne le permet pas.
